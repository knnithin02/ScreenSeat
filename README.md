🎬 ScreenSeat

Movie Ticket Booking Web App with Seat Selection

ScreenSeat is a modern web application that allows users to browse movies, select show timings, and book seats through an interactive UI. The project focuses on delivering a smooth and intuitive seat booking experience similar to real-world platforms.

🚀 Live Demo

🔗 https://preview--movie-preview-prime.lovable.app/

🧠 Problem Statement

Booking movie tickets online should be quick and intuitive, but many systems lack smooth seat selection and user-friendly interfaces.

💡 Solution

ScreenSeat provides a clean and interactive interface where users can:

View available seats
Select preferred seats visually
Experience a seamless booking flow

✨ Features

🎟️ Interactive seat selection UI
📅 Show timing/date selection
🎬 Movie browsing interface
⚡ Fast and responsive design
🎨 Modern UI using Tailwind & shadcn

🛠️ Tech Stack

Category	Technology

Backend	Supabase
